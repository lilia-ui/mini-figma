# Лиля Самойленко — Mini Figma

Репозиторий учебного проекта: лендинг личной страницы и редактор фигур, который
работает прямо в браузере.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Лендинг: статическая страница без сборки и внешних запросов |
| `assets/` | Картинки лендинга: скриншот редактора и превью для ссылки |
| `mini-figma/` | Редактор фигур на React 19, TypeScript, Vite 8 и Tailwind CSS 4 |
| `.github/workflows/deploy.yml` | Сборка и публикация на GitHub Pages по пушу в `main` |
| `LANDING-SPEC.md` | Техзадание лендинга: структура и тексты |
| `AUDIT.md` | Аудит проекта с приоритетами и протоколом проверок |

## Что опубликовано

- лендинг — <https://lilia-ui.github.io/mini-figma/>
- редактор — <https://lilia-ui.github.io/mini-figma/mini-figma/>

## Как запустить редактор локально

```bash
cd mini-figma
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173/`. Подробности —
в [`mini-figma/README.md`](mini-figma/README.md).

## Правила проекта

Правки делаются в ветках `refactor/*`, каждая — отдельным коммитом. `main` не
правится напрямую, публикация и слияние — только по прямому указанию автора.
Полный набор правил — в [`AGENTS.md`](AGENTS.md).
