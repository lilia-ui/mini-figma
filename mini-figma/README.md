# Mini Figma

Минималистичный редактор фигур на **Vite**, **React**, **TypeScript** и **Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Проверка типов и production-сборка:

```bash
npm run build
npm run lint
```

## Возможности текущего шага

- бесконечный холст с адаптивной сеткой;
- создание прямоугольников и эллипсов перетаскиванием;
- выделение фигур рамкой с восемью маркерами;
- перетаскивание выбранных фигур мышью;
- панель слоёв с выбором фигуры по клику;
- панели свойств и инструментов;
- панорамирование зажатым `Space` и мышью;
- зум колесом мыши в диапазоне 10–400%;
- центрирование начала координат после загрузки.

## Архитектура

```text
src/
├── components/   # зоны интерфейса
├── constants/    # настройки инструментов и камеры
├── hooks/        # логика камеры, фигур и будущих hotkeys
├── types/        # общие доменные типы
├── utils/        # чистая математика координат
├── App.tsx       # сборка интерфейса
├── index.css     # глобальные стили и Tailwind
└── main.tsx      # точка входа
```
