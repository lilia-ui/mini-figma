# Mini Figma

Минималистичный редактор фигур на **Vite**, **React**, **TypeScript** и **Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Дев-сервер открывает приложение по адресу `http://localhost:5173/mini-figma/`, а не в корне:
путь `/mini-figma/` задан в `vite.config.ts`, чтобы собранный редактор ложился рядом с
лендингом. На Windows можно запустить `start.cmd` — зависимости доставятся автоматически.

Проверка типов и production-сборка:

```bash
npm run build
npm run lint
```

## Возможности

- бесконечный холст с адаптивной сеткой;
- создание прямоугольников и эллипсов перетаскиванием;
- выделение фигур рамкой с восемью маркерами;
- перетаскивание выбранных фигур мышью;
- панель свойств: X, Y, W и H можно не только посмотреть, но и вписать руками;
- панель слоёв с выбором фигуры по клику и удалением;
- отмена и повтор: кнопки в панели инструментов и `Ctrl+Z` / `Ctrl+Shift+Z`;
- горячие клавиши `V`, `R`, `O`, `Delete`, `Backspace`;
- перемещение фигур стрелками, `Shift` — крупный шаг;
- панорамирование зажатым `Space` и мышью;
- зум колесом мыши в диапазоне 10–400%;
- центрирование начала координат после загрузки.

## Архитектура

```text
src/
├── components/   # зоны интерфейса
├── constants/    # настройки инструментов и камеры
├── hooks/        # логика камеры, фигур и горячих клавиш
├── types/        # общие доменные типы
├── utils/        # чистая математика координат
├── App.tsx       # сборка интерфейса
├── index.css     # глобальные стили и Tailwind
└── main.tsx      # точка входа
```

## Публикация

Пуш в `main` собирает редактор и выкладывает его на GitHub Pages: редактор — по адресу
`/mini-figma/`, лендинг — в корне. Если редактор публикуют по другому пути, переопределите
базу при сборке:

```bash
BASE_PATH=/editor/ npm run build
```

Значение должно совпадать с тем, по какому URL отдаётся каталог `dist/mini-figma`.
