## P0 — критично

| № | Проблема | Файл:строка | Что сделано |
| --- | --- | --- | --- |
| 1 | `event.preventDefault()` в `onWheel` не работает. React 19 регистрирует `wheel` на корневом контейнере с `{ passive: true }` (`react-dom-client.development.js:20939-20954`), поэтому вызов `preventDefault()` внутри обработчика — no-op: браузер всё равно выполняет прокрутку, а в консоль падает ошибка на каждое колесо мыши. Заявленная в README функция «зум колесом мыши» не может подавить нативное поведение. | `mini-figma/src/components/Canvas.tsx:110-119, 254` | Проп `onWheel` убран, добавлен нативный слушатель `wheel` с `{ passive: false }` через `useEffect`; актуальный обработчик хранится в ref, чтобы не переподписываться на каждом зуме. |

## Как проверялось

- `npm run lint` (oxlint, 17 файлов, 116 правил) — 0 ошибок, 0 предупреждений.
- `npm run build` (`tsc -b` со `strict: true` + `vite build`) — успешно, с чистого состояния
  (предварительно удалены `dist` и кэш `tsc`).
- Секреты: просканированы файлы проекта и вся история git по паттернам токенов/ключей/приватных
  ключей — совпадений нет. Единственное срабатывание — `id-token: write` в workflow, это имя
  права GitHub Actions, а не секрет.
- Исправление P0 подтверждено по исходникам React (`react-dom-client.development.js:20939-20954`,
  `wheel` регистрируется с `passive: true`) и по собранному бандлу: присутствует
  `addEventListener("wheel", …, {passive:!1})`, а проп `onWheel` из разметки убран.
- Раскладка публикации проверена на живом HTTP-сервере, повторяющем поведение GitHub Pages
  (каталоговый `index.html`): `/` → 200 (лендинг), `/mini-figma/` → 200 (редактор),
  `/mini-figma/favicon.svg`, JS и CSS → 200, у редактора абсолютные пути `/mini-figma/assets/…`.
  Прогонялось ровно то, что делает CI: `lint` → `build` → `cp ../index.html dist/index.html`.
- Лендинг `index.html` проверен статически: CSS разобран `postcss` (15 правил), HTML-теги
  сбалансированы, скобки CSS сбалансированы, присутствуют `doctype`/`lang`/`charset`/`viewport`/
  `description`/`title`, нет `console.log`, `debugger`, `TODO`.

Ограничение: интерактивная проверка в браузере (просмотр консоли) была недоступна — среда не
предоставляет подключённого десктопного браузера. Поэтому вместо неё выполнены перечисленные
выше проверки; поведение зума подтверждено на уровне регистрации слушателя, а не кликом мыши.
Правки палитры (P2.5–P2.7) сознательно не выполнялись именно поэтому: без возможности открыть
страницу такой рефакторинг нельзя подтвердить визуально.
